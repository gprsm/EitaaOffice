# GMI 1 Windows acceptance checklist

این بررسی را ابتدا روی یک کپی آزمایشی از داده‌های واقعی انجام دهید.

## نصب و Migration

- [ ] از نسخهٔ UI 3.3 با `backup_now.bat` پشتیبان بگیرید.
- [ ] برنامهٔ قبلی را کامل ببندید.
- [ ] بستهٔ GMI 1 را در پوشه‌ای تازه استخراج و داده‌ها را با مسیر ارتقای معمول
      منتقل کنید.
- [ ] `install_app.bat` و سپس `run_doctor.bat` را اجرا کنید.
- [ ] Doctor باید Bridge dev26، Core dev19 و schema 9 را تأیید کند.
- [ ] کنار دیتابیس منتقل‌شده، فایل
      `messages.sqlite3.pre-schema9-v8.bak` باید ایجاد شده باشد.
- [ ] تعداد گفتگوها و پیام‌های قدیمی را با نسخهٔ قبل مقایسه کنید.

## پذیرش گالری واقعی

- [ ] یک گروه یا کانال دارای پست واقعی چندعکسی را باز کنید.
- [ ] همهٔ عکس‌های همان پست باید در یک کارت «گالری» دیده شوند.
- [ ] متن همراه باید یک‌بار و در همان کارت نمایش داده شود.
- [ ] پیام مستقلِ قبل و بعد نباید اشتباهاً وارد گالری شود.
- [ ] انتخاب یا پاک‌کردن انتخاب باید تمام اعضای گالری را یکجا تغییر دهد.
- [ ] جست‌وجوی بخشی از متن یا شناسهٔ یکی از اعضا باید کل گالری را نشان دهد.
- [ ] گالری‌ای که مرز صفحهٔ محلی را قطع می‌کند نباید ناقص نمایش داده شود، به
      شرط آنکه اعضا قبلاً در SQLite همگام شده باشند.
- [ ] عکس، فایل و ترکیب رسانه‌ای غیرعادی را بررسی و نتیجه را ثبت کنید.

## WordPress و جلوگیری از استفادهٔ ناقص

- [ ] ابتدا فقط Draft و یک پست آزمایشی غیرحساس بسازید.
- [ ] انتخاب یک گالری باید همهٔ شناسه‌های منبع آن را وارد پیش‌نمایش کند.
- [ ] پس از ثبت موفق، همهٔ اعضا باید «استفاده‌شده» دیده شوند.
- [ ] تلاش برای استفادهٔ دوباره از بخشی از همان گالری باید مسدود و سابقهٔ
      استفاده نمایش داده شود.

## رگرسیون UI 3.3

- [ ] گفت‌وگوی دارای خوانده‌نشده از مرز خوانده‌نشده باز شود.
- [ ] گفت‌وگوی بدون خوانده‌نشده از موقعیت تقریبی ذخیره‌شده باز شود.
- [ ] Scroll، دریافت صفحهٔ قدیمی‌تر و جابه‌جایی سریع بین گفتگوها روان بماند.
- [ ] دسته‌ها، برچسب‌ها، Draft و Update وردپرس مثل UI 3.3 کار کنند.

## نتیجه

- [ ] نتیجهٔ آزمون و نمونهٔ گالری پذیرفته شد.
- [ ] در صورت شکست، برنامه متوقف و از کپی
      `.pre-schema9-v8.bak` بازیابی شد؛ تنها نسخهٔ پشتیبان overwrite نشد.

ایندکس‌گذاری محتوایی در این Checklist نیست؛ آن قابلیت هنوز فقط طرح Lab است.
