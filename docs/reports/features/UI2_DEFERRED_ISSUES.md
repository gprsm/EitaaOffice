# Deferred issues after UI 2 Scroll Repair

These items were reported during UI 1.1 field use but are deliberately outside the isolated Scroll Repair scope:

1. Sending a file to members of a group failed.
2. The third section in the Conversation Operations tab remains disabled.
3. Some group/channel avatars are not displayed. UI 1.1 intentionally permits automatic avatar loading only from an existing local cache; a separate explicit avatar-retrieval design is required before changing that policy.

None of these items is claimed as fixed by UI 2. They must be handled in a separate functional package after UI 2 is accepted and frozen.
