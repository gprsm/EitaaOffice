# گزارش تکمیل تم دارک Material UI

تاریخ: ۲۰۲۶/۰۵/۰۴ (2026-07-26)

## نتیجه

تم برنامه به‌صورت سراسری و ثابت روی حالت دارک قرار گرفت. حالت‌های روشن و System از مسیر اجرای رابط حذف شدند تا میان اجزای Material UI، اجزای قدیمی CSS، پنجره‌های Portal و کنترل‌های بومی مرورگر اختلاف رنگ ایجاد نشود.

## تغییرات اصلی

- `ui/src/theme.ts`
  - تعریف پالت ثابت با `palette.mode = "dark"` و `direction = "rtl"`.
  - تعریف رنگ‌های معنایی برای پس‌زمینه، سطوح، ورودی‌ها، مرزها، متن، حالت غیرفعال و رنگ‌های وضعیت.
  - تنظیم پیش‌فرض و ظاهر اجزای اصلی Material UI شامل Paper، Card، Dialog، Drawer، Menu، TextField، Select، Checkbox، Radio، Switch، Button، Chip، Tabs، Table، Tooltip، Skeleton و LinearProgress.

- `ui/src/main.tsx`
  - اتصال تم ثابت به `ThemeProvider`.
  - فعال‌سازی `CssBaseline` با `enableColorScheme`.
  - تنظیم `color-scheme: dark` در سند و همگام‌سازی نشانگر داخلی تم.
  - ثابت‌شدن ظاهر اعلان‌ها روی حالت دارک.

- `ui/src/App.tsx`
  - حذف امکان چرخش بین Light/Dark/System.
  - جایگزینی کلید تم با نشانگر خوانای «تم برنامه: تاریک».

- `ui/src/styles.css`
  - هماهنگ‌سازی کامل پوسته قدیمی با توکن‌های دارک.
  - پوشش پنل‌ها، باکس‌ها، ورودی‌ها، Selectها، مودال‌ها، منوها، Drawerها، فرم تنظیمات، مخاطبان، ارسال گروهی، وردپرس، پیام‌ها، تقویم و وضعیت‌های اطلاع/موفقیت/هشدار/خطا.
  - تعریف مستقل حالت‌های Hover، Focus، Checked، Disabled و Selected برای کنترل‌های قدیمی و Material UI.

## باکس‌ها، چک‌باکس‌ها و سوییچ‌ها

- باکس‌ها از سطح‌های معنایی استفاده می‌کنند و دیگر رنگ سفید ثابت ندارند.
- چک‌باکس انتخاب‌شده: `#64b5f6`.
- چک‌باکس انتخاب‌نشده: `#778595`.
- چک‌باکس غیرفعال: `#4c5662` با سطح `#151b23`.
- حلقه فوکوس: آبی نیمه‌شفاف با کنتراست مناسب.
- سوییچ فعال: Track آبی `#64b5f6` و Thumb روشن `#d9edff`.
- سوییچ غیرفعال و متن کنارش از رنگ‌های Disabled استفاده می‌کنند.
- ایراد قدیمیِ متن بسیار تیره کنار چک‌باکس‌های تنظیمات شناسایی و اصلاح شد؛ متن فعال، انتخاب‌شده و غیرفعال اکنون سه سطح خوانایی مستقل دارند.

## نکته فنی بازیابی‌شده

یک ناسازگاری Runtime میان Selectorهای تو‌در‌توی Theme Override و پردازش RTL توسط Emotion/Stylis باعث خطای اجرای Stylis می‌شد. Overrideهای ساختاری به‌صورت تخت در Theme باقی ماندند و Selectorهای حالت در CSS نهایی قرار گرفتند. پس از این اصلاح، خطای Runtime برطرف شد و RTL همچنان فعال باقی ماند.
