# گزارش اصلاح حالت تاریک بخش وردپرس

تاریخ: ۲۰۲۶-۰۷-۲۶

## نتیجه

سطوح شیری‌رنگ پنل وردپرس با سطوح تاریک هماهنگ با تم Material UI جایگزین شد. عنوان‌های `fieldset`، انتخاب نوع انتشار، رادیوها و نوار شناور بالای ستون وردپرس اکنون در دسکتاپ و موبایل خوانا و یکپارچه‌اند.

## علت اشکال

قاعده قدیمی و اختصاصی `.wp-fieldset .fieldset-legend` پس‌زمینه `#eee9e2` را اعمال می‌کرد، اما قاعده عمومی جدید فقط رنگ متن را سفید کرده بود. به‌علت اختصاصی‌تر بودن قاعده قدیمی، ترکیب پس‌زمینه روشن و متن روشن ایجاد می‌شد. برای `publish-choice` و بخش شناور بالای Composer نیز چند لایه استایل قدیمی هم‌زمان فعال بودند.

## تغییرات

- افزودن یک لایه نهایی و اختصاصی برای سطوح تاریک پنل وردپرس.
- تغییر پس‌زمینه عنوان `fieldset` به `#202c39` و رنگ متن به `#eaf3fb`.
- تغییر پس‌زمینه `publish-choice` به `#101821`.
- طراحی حالت عادی و انتخاب‌شده برای دو گزینه «پیش‌نویس» و «انتشار مستقیم».
- تعریف رنگ مستقل برای رادیوی انتخاب‌شده و انتخاب‌نشده.
- بازطراحی نوار بالای Composer با گرادیان تاریک، سایه، آیکن زمینه‌ای و حالت sticky.
- تعریف هویت آبی برای تب وردپرس و هویت سبز برای تب عملیات گفتگو.
- تیره‌سازی فهرست دسته‌ها، برچسب‌های انتخاب‌شده، بخش کلمات کلیدی و پیام تأیید انتشار.
- تبدیل گزینه‌های انتشار به یک ستون در عرض موبایل.
- هماهنگ‌کردن آزمون قدیمی صفحه ورود با محل فعلی مؤلفه `LoginSurface`.
