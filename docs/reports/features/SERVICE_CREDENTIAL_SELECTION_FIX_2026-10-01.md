# اصلاح نمایش انتخاب‌های گواهینامهٔ سرویس

تاریخ: 2026-10-01؛ مرجع: F-104 / V-267.

## علت و اصلاح

مالک گزارش کرد گزینه‌هایی مانند «ارسال پیام» و «وضعیت ارسال» پس از انتخاب روشن نمی‌مانند. شاهد مرورگر پیش از اصلاح نشان داد theme به Chip انتخاب‌شده و انتخاب‌نشده پس‌زمینهٔ یکسان می‌دهد. state انتخاب باقی بود، ولی از ظاهر قابل تشخیص نبود و وضعیت checked در دسترس ابزارهای کمکی قرار نداشت.

سه فهرست scope، Provider و حساب در `ui/src/ServiceAccountSettingsPanel.tsx` به Checkbox کنترل‌شده با برچسب تبدیل شدند. قرارداد API و state صدور تغییر نکردند. وضعیت با تیک و checked قابل مشاهده است و به focus یا رنگ Chip وابسته نیست.

## بررسی

- UI check، observability و build: exit=0. هشدار معمول اندازهٔ chunk در build باقی است.
- مرورگر پس از بازخوانی باندل روی سرویس موجود: انتخاب ارسال، وضعیت، افزودن مخاطب، ایتا و حساب؛ انتقال focus به نام سرویس؛ همهٔ checkedهای انتخاب‌شده باقی ماندند و فرم معتبر شد.
- Space انتخاب ارسال را لغو کرد و وضعیت ارسال انتخاب‌شده ماند. حذف تیک حساب، دکمهٔ ساخت را غیرفعال کرد. پنجره بدون submit بسته شد.
- هیچ credential، contact یا پیام تازه ایجاد نشد. این شاهد UI است و تأیید دریافت OTP یا اتصال گرم Provider نیست.
- Python و wheel تغییر نکردند؛ full Backend معتبر V-265 به علت تغییر صرفاً نمایشی تکرار نشد.
