# GMI 4.2 — Architecture and Scope

## دامنه

- RTL واقعی و Theme روشن/تاریک/سیستم بر پایه Material UI و Emotion RTL.
- ورودی «مخاطبان ایتا» در منوی مشکی سمت راست.
- دفترچه واقعی سرور ایتا: list/add/remove از طریق Core 7.4.5 GMI1.
- دفترچه دائمی محلی، دسته‌بندی، ورود انفرادی و Excel/CSV/TXT.
- انتخاب اختیاری برای افزودن ورودی‌های محلی به مخاطبان واقعی ایتا.
- Target Builder با فیلتر سخت‌گیرانه دسته، Pagination و Preview.
- کادر ارسال متن/عکس/فایل زیر محتوای گفتگو.
- Cache و Lazy loading برای آواتار و رسانه.
- نقطه اتصال مستند برای تمپلیت پیام آینده.

## مرزهای ثابت

- Core wheel تغییر نکرده است.
- Scheduler و Priorityهای موجود حفظ شده‌اند.
- WordPress و منطق Scroll/Grouped Media تغییر ماهوی نکرده‌اند.
- هیچ ارسال خودکار، زمان‌بندی تمپلیت یا دورزدن محدودیت حساب پیاده نشده است.

## دیتابیس

- Core SQLite schema: 9
- Content-index schema: 2
- Contact schema: 1
- مخاطبان واقعی ایتا در دیتابیس محلی Core جایگزین نمی‌شوند؛ Snapshot کوتاه‌مدت در حافظه Cache می‌شود.

## محدودیت شناخته‌شده آواتار اشخاص

Core فعلی در پاسخ `contacts.getContacts`، `UserProfilePhoto` را به مدل Domain منتقل نمی‌کند. بنابراین Avatar شخص وقتی قابل واکشی است که همان User در کاتالوگ گفتگو مرجع عکس معتبر داشته باشد. در غیر این صورت UI حروف اول نام را نمایش می‌دهد. کانال و گروه از مرجع عکس Dialog پشتیبانی می‌شوند.
