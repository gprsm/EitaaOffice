# پشتیبان‌گیری و بازیابی

## پشتیبان‌گیری

`backup_now.bat` یک ZIP دارای Manifest و SHA-256 می‌سازد و به‌طور پیش‌فرض Session، دیتابیس، تنظیمات، Compositionها، رسانه‌ها، ترجیحات UI و فونت‌های اختیاری را نگه می‌دارد.

برای پشتیبان سبک بدون رسانه:

```bat
.venv\Scripts\python.exe scripts\backup_runtime.py --without-media
```

## بازیابی

1. Bridge را کاملاً ببندید.
2. `restore_backup.bat` را اجرا و فایل ZIP را انتخاب کنید.
3. ابزار ابتدا از وضعیت فعلی یک پشتیبان اجباری می‌سازد.
4. تمام فایل‌ها پیش از اعمال با SHA-256 بررسی می‌شوند.
5. پس از موفقیت، Bridge را دوباره اجرا کنید.

فایل ZIP با مسیر ناامن، Manifest ناشناخته یا Checksum نادرست اعمال نمی‌شود.

## مجوز دستگاه در Backup

فایل `data\licensing\activation.dat` ممکن است همراه state محلی Backup شود، اما هم با DPAPI همان Windows user محافظت شده و هم مجوز داخل آن برای fingerprint دستگاه امضا شده است. Restore روی رایانه یا Windows user دیگر مجوز قابل استفاده ایجاد نمی‌کند؛ اجرای بعدی کد درخواست تازه نشان می‌دهد و نیازمند صدور فعال‌سازی جدید است. این رفتار خطا یا خرابی Backup نیست.
