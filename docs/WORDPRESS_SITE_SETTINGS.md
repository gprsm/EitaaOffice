# تنظیم سایت‌های WordPress

پنجره Settings امکان افزودن، ویرایش، حذف و تعیین سایت پیش‌فرض را فراهم می‌کند. اطلاعات قابل تنظیم شامل URL، نام کاربری، Application Password، وضعیت پیش‌فرض نوشته، دسته پیش‌فرض، TLS، Timeout و Retry است.

- رمز و نام کاربری در `.env` ذخیره می‌شوند و API هرگز مقدار آن‌ها را برنمی‌گرداند.
- پیش از هر تغییر، نسخه‌ای از `bridge.json` و `.env` در `backups\settings` ساخته می‌شود.
- HTTP ناامن فقط برای localhost و با فعال‌سازی صریح مجاز است.
- دکمه Test اتصال و مجوز WordPress را بدون انتشار نوشته بررسی می‌کند.
- حذف سایت نیازمند تأیید صریح است و حداقل یک سایت باید باقی بماند.
