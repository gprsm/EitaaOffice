دو فایل فونت خریداری‌شده IRANSans را با نام‌های دقیق زیر در همین پوشه قرار دهید:

IRANSansWeb-Regular.woff2
IRANSansWeb-Bold.woff2

نسخه Regular برای متن‌های عادی و نسخه Bold برای عنوان‌ها، Legendها، Badgeها و Tagها استفاده می‌شود.
فایل‌های فونت عمداً داخل بسته پروژه قرار نگرفته‌اند.

پس از قرار دادن فونت‌ها، setup_ui.bat یا install_app.bat را دوباره اجرا کنید.
