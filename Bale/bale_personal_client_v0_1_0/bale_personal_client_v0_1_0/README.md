# Bale Personal Client v0.1.0

Independent research-grade Python framework for testing a personal Bale Messenger client. It includes phone authentication, encrypted session storage, gRPC-Web, WebSocket handshake/RPC, messaging, history, files, contacts, presence, live updates, a raw Protobuf RPC lab, CLI, and a Tkinter test UI.

See **README_FA.md** for the complete Persian guide and **PROTOCOL_NOTES.md** for confidence levels and protocol assumptions.

This project is unofficial. Use only with accounts you own or are explicitly authorized to test.
